### (engl. Estimating Rasopathy Prevalence and Associated Diseases Using FinnGen Data)
### Author: Liisa Niinistö
### Year: 2026
### Link to thesis (in Finnish): https://www.utupub.fi/handle/XXXXX/XXXXXX

## Description

The aim of the thesis was to estimate the prevalence of rasopathies in the Finnish population using the FinnGen dataset, which combines genetic data and registry-based health data from approximately half a million Finnish individuals. The prevalence of rasopathies was assessed in terms of both the number of diagnoses and the prevalence of rasopathy variant carriers. The second aim of the thesis was to investigate other diseases and conditions associated with rasopathy variants using a phenome-wide association study (PheWAS).

The R code file includes all analyses performed in the thesis.

## Data

Access to individual-level FinnGen data is restricted. Only datasets from public sources that were used in the thesis are included in this repository.
